  all work uses the canonical invocation/Program/execution integration.

  for product acceptance. Live-provider calls are explicit, private and bounded.
- Preserve SOLID/hexagonal boundaries, cohesive classes, minimal idiomatic Python,
  precise types, meaningful models/enums and async resource ownership throughout.
